# Living Car

Living Things / Cloud DNA — Concept by Evgenii Bogomazov-Pusser, Independent Researcher, Israel.

## Открыть

Откройте **index.html в корне проекта** кнопкой браузера в PyCharm. Готовый сайт уже собран. Установка Python, Node, запуск Vite или отдельная сборка для просмотра не нужны.

В корне лежат обычные файлы сайта:

```
index.html
style.css
app.js
assets/physics.js
models/
.nojekyll
```

HTML небольшой; стили, 3D и физический движок находятся в отдельных файлах. Все пути относительные. Расчёты выполняются на устройстве посетителя. Данные для физики встроены в assets/physics.js, поэтому сайт не требует API, внешнего сервера вычислений или загрузки моделей с чужого домена.

## GitHub Pages

Репозиторий: https://github.com/EvgeniyPusser/living-car

Загрузите изменения в существующий репозиторий. В Settings → Pages выберите Deploy from a branch → main → /(root). Публиковать нужно **из корня**, не из web, docs или dist.

Окружения, зависимости, локальные профили и архивы исключены через .gitignore. Папку assets нужно загрузить вместе с index.html: там находится физический движок. Размер assets/physics.js около 15 МБ; это отдельный файл ресурсов, а не огромный HTML.

Для ручной загрузки подготовлен архив living-car-github.zip. В нём только готовые файлы сайта. Его можно распаковать и загрузить содержимое в корень репозитория; сам ZIP на GitHub Pages вместо сайта не публикуют.

## Использование

Выберите сценарий. Нажмите Play под 3D-моделью. Мышью можно вращать модель и приближать её. Living Car / Conventional переключает сравниваемые конструкции. После изменения скорости или ресурсов нажмите Run paired experiment. Export results сохраняет обе рассчитанные траектории в JSON.

Сценарии: боковой контакт, узкий зазор, фронтальный удар, косой удар, локальный ремонт покрытия. Отображаются контактные силы, ускорение ячейки, повреждения, пластическая деформация и расход энергии.

## Научные ограничения

Это упрощённая механическая модель MuJoCo, а не реальный краш-тест. Материалы и адаптивная оболочка гипотетические. Жёсткие панели соединены пружинами, демпферами и механическими связями. Повреждение и вторжение в пассажирский объём — расчётные прокси, а не оценки травм. Обученная нейросеть, FEM, полная виртуальная жизнь и реальный облачный интеллект в этой версии отсутствуют. Результат не обязан быть лучше обычного кузова.

Подробные уравнения и ограничения: docs/MODEL.md. Первый воспроизводимый опыт: results/first-experiment/RESULTS.md.

## Разработка

Исходники браузерной логики и инструменты сборки находятся в tools/browser/. Для посетителя они не нужны. Пересборка разработчиком: node tools/browser/build-static.mjs (после установки зависимостей в tools/browser). Проверка готовых файлов: node tools/browser/verify-static.mjs.

Исходный Python-прототип и исследования сохранены в src/living_car/, tests/, pyproject.toml и results/. Desktop-запуск — Start Living Car.cmd. Они не требуются для работы сайта.
